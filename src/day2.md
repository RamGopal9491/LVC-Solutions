Git Branch
View branches:

git branch

The * shows the current branch.

Create a Branch git switch -c feature-name
Older method:

git checkout -b feature-name

Creates a new branch and switches to it.

To rename a branch:

git branch -m new-name 15. git checkout vs git switch Checkout git checkout branch-name

Older, multi-purpose command.

Switch git switch branch-name

Modern command specifically for switching branches.

git switch -c new-branch

Creates and switches to a branch.
